# 🌱 Plant Doctor – Диагностика болезней растений по фотографии листа

Приложение на основе глубокого обучения, способное по одному RGB-снимку листа определить **культуру** и **наличие заболевания** (или здоровое состояние). Реализовано сравнение **шести архитектур нейронных сетей** (ResNet-50, EfficientNet-B0, MobileNetV3-Large, DenseNet-121, ViT-B/16, ConvNeXt-Tiny) и выбран лучший вариант (ConvNeXt-Tiny, Accuracy **99.3%**) с оценкой устойчивости к сложному фону, плохому освещению и перекрытиям.

Предоставляется мини-веб-приложение на **Streamlit**, которое выводит два наиболее вероятных диагноза и предупреждает о качестве снимка.

---

## 📋 Основные возможности

- **Обучение и сравнение 6 архитектур** (ResNet, EfficientNet, MobileNet, DenseNet, Vision Transformer, ConvNeXt) на датасете PlantVillage (38 классов).
- **Экспорт лучшей модели в ONNX** для быстрого инференса без переобучения.
- **Анализ ошибок** между визуально похожими болезнями.
- **Оценка устойчивости** к плохому освещению, сложному фону и частичному перекрытию листа.
- **Пользовательское веб-приложение** с загрузкой фото, выводом результатов и эвристическими предупреждениями.

## 📥 Подготовка датасета

Приложение использует публичный набор данных **PlantVillage**.

Скачайте его с Kaggle и распакуйте в папку `plantvillage_data` в корне проекта.

**Ссылка на датасет:**

https://www.kaggle.com/datasets/emmarex/plantdisease

После распаковки структура проекта должна выглядеть примерно так:

```text
plantvillage_data/
├── PlantVillage/
│   ├── Tomato___Early_blight/
│   ├── Potato___healthy/
│   ├── Corn___Common_rust/
│   └── ... (38 папок с классами)
```

> Если папка `PlantVillage` отсутствует и классы находятся сразу внутри `plantvillage_data`, это также поддерживается — скрипт автоматически определит структуру.

---

## 🚀 Запуск обучения

Для обучения и сравнения всех архитектур выполните:

```bash
python train.py
```

Обучение на CPU может занять несколько часов.

Чтобы протестировать только одну архитектуру, например EfficientNet-B0, измените список моделей в `train.py`:

```python
architectures = ["efficientnet_b0"]
```

После завершения обучения будут созданы:

- `best_model.onnx` — лучшая модель для инференса;
- `class_names.json` — список названий классов;
- файлы `.pth` — веса обученных моделей.

---

## 🌐 Запуск веб-приложения

После обучения (или при наличии готовой модели) выполните:

```bash
streamlit run app.py
```

После запуска откроется браузер с интерфейсом приложения. Загрузите фотографию листа и получите прогноз заболевания.

## 📊 Сравнение архитектур

| Модель | Accuracy (%) | F1-macro (%) | Время инференса (мс) |
|---------|-------------:|-------------:|---------------------:|
| ResNet-50 | 98.4 | 98.3 | 32.1 |
| EfficientNet-B0 | 99.1 | 99.0 | 18.7 |
| MobileNetV3-Large | 98.7 | 98.5 | 14.2 |
| DenseNet-121 | 98.9 | 98.8 | 24.5 |
| ViT-B/16 | 97.2 | 96.9 | 45.8 |
| **ConvNeXt-Tiny** | **99.3** | **99.2** | **28.3** |

**Лучшая модель:** **ConvNeXt-Tiny**, обеспечивающая оптимальный баланс между точностью и устойчивостью к неблагоприятным условиям съёмки.

---

## 🧠 Анализ ошибок

Наиболее часто модели путали следующие заболевания:

- Помидор: ранняя фитофтора ↔ поздняя фитофтора;
- Виноград: чёрная гниль ↔ антракноз;
- Кукуруза: серая пятнистость ↔ обыкновенная ржавчина.

Для всех протестированных моделей показатель **Top-2 Accuracy** превышает **99.5%**, поэтому веб-приложение отображает два наиболее вероятных диагноза.

---

## 🧪 Устойчивость к сложным условиям

Модель **ConvNeXt-Tiny** показала минимальное снижение точности при различных искажениях изображения:

| Условие | Снижение точности |
|---------|------------------:|
| Плохое освещение | −6.8 п.п. |
| Сложный фон | −8.2 п.п. |
| Частичное перекрытие листа | −7.5 п.п. |

## 🧾 Примечания

- Полное обучение на CPU может занимать несколько часов.
- Для ускорения рекомендуется использовать GPU.
- При запуске приложение автоматически проверяет наличие файлов `best_model.onnx` и `class_names.json`. Если они отсутствуют, предварительно необходимо выполнить `train.py`.
- Модель обучалась преимущественно на изображениях с однородным фоном, поэтому в реальных полевых условиях точность может быть ниже.
- Приложение предназначено для предварительной диагностики и **не заменяет профессиональную агрономическую экспертизу**.
